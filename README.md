I did this Voice Assistant 3/4 years ago for a Raspberry Pi as the final project of my TGPSI course. This was a Voice assistant that was placed inside a Iron Man helmet, hence the rgb lights. 
Almost everything is "Hard coded", as it was supposed to be a simple program.

PAY CLOSE ATTENTION TO THE COMMENTS

You'll need a raspbery 4b RUNNING LINUX (the 3 should work aswell, but I can't guarantee). I used a RGB ring for the lights placed inside the helmet. You can just remove that part if you don't want to use them.

You need to install every single library otherwise it won't work. And also get the API keys, I used the free ones.
